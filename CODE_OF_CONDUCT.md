# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be kind, assume good intent, welcome newcomers, and keep criticism about the work, not the person.
Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainer through the contact on the
[maintainer's GitHub profile](https://github.com/joseairosa). Reports are handled confidentially.
